# 🎓 Student Record Management System

A professional **Java Console Application** for managing student records with a menu-driven interface. Built with pure Java (no external dependencies) - perfect for internships and academic projects.

---

## 📋 Project Description

This application provides a complete CRUD (Create, Read, Update, Delete) system for managing student records in a console environment. It features input validation, formatted table output, and professional error handling.

**Tech Stack:**
- Java 17+
- Standard Java Libraries only
- Console-based UI with printf formatting

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| ➕ **Add Student** | Add new students with validation for ID, age, CGPA, and email |
| 👁️ **View All** | Display all students in a formatted table with total count |
| 🔍 **Search** | Find students by ID with detailed information display |
| ✏️ **Update** | Modify existing student details with validation |
| 🗑️ **Delete** | Remove students with confirmation prompt |
| ✅ **Validation** | Duplicate ID check, age (16-40), CGPA (0-10), email format |
| 🎨 **Professional UI** | Attractive console layout with separators and emojis |
| 🛡️ **Error Handling** | Graceful handling of invalid inputs and missing records |
